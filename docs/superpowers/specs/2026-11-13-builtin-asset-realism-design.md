# 内置素材真实感升级设计（2026-11-13）

## 1. 意图与范围

用户反馈全部内置素材“都太方块”，并授权由实现者决定方向。本次覆盖目录现有 **6 类 16 件**，不是只美化三件校园地标。

方向是实现者选择、用户授权决定的：**真实比例的精细程序化低模**，保留 Three.js 纯几何生成，不下载或引入外部模型，不追求照片级 PBR/测绘级复刻。

## 2. 目标 / 非目标 / 反目标

**目标**
- 消除未处理的直角 Box 观感：实体盒体统一小半径圆角与平滑法线，细长杆件按语义改为圆柱。
- 植被使用更连续的树冠轮廓、分支与花瓣；设施增加板条、框架、底座、灯罩、桶口等可辨细节。
- 东大门有曲面翘檐、瓦垄、拱券与门墩线脚；操场有圆管球门、球网、座椅、弧形看台顶棚和飘动旗面；致远楼有窗框分格、立面腰线、入口门框和更合理的课桌椅轮廓。
- 保持目录、真实尺寸、componentId 语义、碰撞规则、路线、灯光绑定、持久化与静态合批链路可用。

**非目标**
- 不改变素材数量、尺寸配置或放置交互。
- 不开放致远楼上层，不改看台不可登临规则，不增加动态布料或植被动画。
- 不引入贴图库、GLB、Draco、网络运行时依赖。

**反目标**
- 仅把 BoxGeometry 换成更大的 Box，或只改颜色后宣称“真实”。
- 为视觉细节新增无分类 Mesh，破坏碰撞完整性。
- 用密集倒角和瓦片把三角面推到失控，或用视觉圆柱缩小原有 box 碰撞造成穿插。

## 3. 技术方案

### 3.1 只读注册表与接入点

`sceneAssetGeneratorRegistry.js` 继续只读。新增 `src/three/world/proceduralGeometry.js` 提供圆角盒、圆柱杆件等共享纯几何工具；新增 `src/three/sandbox/builtinAssetRealism.js` 作为内置素材专用视觉后处理。

`createBuiltinSandboxModel` 在原生成器/campus 生成器返回后、任何 componentId 与碰撞声明生成前调用：

`refineBuiltinAssetVisuals(THREE, root, { category, objectType })`

因此旧 13 件仍消费只读注册表，校园三件仍走独立生成器；所有新增 Mesh 都经过既有分类门禁。原 Mesh 的名称、位置与根 userData 保留。

### 3.2 通用几何规则

- 剩余实体 `BoxGeometry` 统一替换为 `RoundedBoxGeometry`（1 段，半径取短边与 0.08m 的受控比例），保持局部包围盒尺寸；Plane/Shape/Ring 等贴地或贴墙薄片不强求圆角。
- `MeshStandardMaterial.flatShading=false`，保留原色，适度降低塑料感；玻璃、发光片和透明度不改语义。
- 杆件用 10–12 边圆柱，保留原中心与长度。碰撞仍由适配层按局部 AABB 生成 box，不以视觉圆柱半径重写物理规则。
- 重复细节优先共享几何与材质，避免为每片瓦/每朵花创建独立材质。

### 3.3 旧 13 件细节清单

- 乔木：12 边树干、至少 5 个分支、细分且轻微不规则的树冠。
- 灌木：细分圆润冠形；花卉：花瓣与叶片的可读轮廓。
- 人行桥：圆角桥面/扶手、圆柱栏杆；廊架：可见屋顶板条；凉亭：坡屋顶而非平盖板。
- 长椅：4 条座板、3 条背板、圆角金属支撑；路灯：圆锥灯罩与底座；垃圾桶：圆角椭圆桶身和桶口；指示牌：双立柱与边框。
- 景观石：细分非对称石形；花坛：圆角边框与更多花茎；篮球架：圆柱支撑和篮筐网。

新增语义只使用既有规则可分类的名称，或显式补充最小 none 规则。

### 3.4 校园三件细节清单

- 东大门：保留 36×13×8 包络与门洞；屋顶按原包围盒换成连续四坡曲面并上翘檐角，加瓦垄、中央/两侧椭圆拱券、门墩底座和顶部线脚。新增 `roof`/`lintel` 为 none，`pier` 为 required。
- 天工体育场：球门改圆管并加网；看台加座椅、顶棚改浅弧面；旗面用细分波浪 Plane。新增 `goal-net`、`stand-seat` 明确 none，其余沿用原规则。
- 致远楼：大体量仍必须是建筑实体，但圆角只作近人尺度收口；上下窗带加竖向 mullion、楼层腰线与入口玻璃门框，椅子改带靠背的挤出 L 轮廓，课桌边缘圆角。所有新增立面件沿用 `window-glass` none 或 `upper`/`wall` required，不改变通道与家具摆位。

### 3.5 性能与持久化

- 校园三件默认实例合计三角面仍 **< 40,000**；新增测试直接统计。
- 不为每次重复细节克隆材质；圆角盒按尺寸/半径缓存共享。
- 所有新增对象仍是普通 Mesh/BufferGeometry，可 toJSON→ObjectLoader；环境绑定目标原 Mesh 不删除。

## 4. 验收与测试

1. 16 件逐一通过既有尺寸包络、碰撞完整性与唯一 componentId 测试。
2. 新视觉测试经真实适配层生成：不得残留未处理实体 `BoxGeometry`；上述逐件细节名称/几何类型/数量断言成立。
3. 东大门门洞与屋顶包络不回归；操场 105×68 球场、8 道跑道不回归；致远楼真实 Rapier 主入口/教室正向与实心翼反向路线保持原结果。
4. 路灯 1 盏 PointLight + 2 绑定、致远楼 3 灯 + 9 绑定、预览环境同步与存档往返不回归。
5. 校园三件三角面合计 <40,000；全量测试只允许既有 9 个基线红；vite build exit 0。
6. 没有用浏览器实测前不得声称视觉验收成功；最后提供用户实测清单。
