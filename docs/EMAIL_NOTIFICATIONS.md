# 邮件通知配置

管理后台 → **邮件通知**（`/admin?view=email`）用于配置 SMTP 和审核通知。该页面仅管理员可见，配置与站点品牌设置分开存放。

## 页面能做什么

- 配置 SMTP 发件服务。
- 配置管理员通知收件人。
- 选择哪些事件发邮件。
- 发送测试邮件。
- 查看最近 30 条发送记录（成功、跳过、失败原因）。
- 维护团队成员的通知邮箱。

## SMTP 配置项

| 字段 | 说明 |
| --- | --- |
| 启用邮件通知 | 关闭时所有通知直接跳过，不连接 SMTP。 |
| SMTP 主机 | 例如 `smtp.example.com`。 |
| 端口 | 常见为 `465`（SSL/TLS）或 `587`（STARTTLS）。 |
| 直接使用 SSL/TLS | 端口 `465` 通常勾选；端口 `587` 通常不勾选。 |
| SMTP 用户名 | 通常是完整邮箱地址；部分企业邮局使用独立账号。 |
| SMTP 密码 | 邮箱密码或服务商提供的 SMTP 授权码。保存后不会回传浏览器。 |
| 发件人名称 | 收件人看到的发件人显示名，例如 `Worldweave`。 |
| 发件邮箱 | 必须是 SMTP 服务允许的代发地址，通常与用户名相同。 |
| 管理员通知收件人 | 多个地址用逗号、分号或换行分隔，最多 20 个。 |

### 密码规则

- 密码只写不读：`GET` 接口只返回 `passwordConfigured`，不返回密码本身。
- 输入框留空表示保持原密码。
- 勾选「清除已保存的 SMTP 密码」并保存后，数据库中的密码会被清空。
- 更换邮箱服务商时，记得同时更新主机、端口、用户名、密码和发件邮箱。

## 通知事件

| 事件 | 收件人 | 内容 |
| --- | --- | --- |
| 新的加入申请 | 管理员 | 姓名、期望用户名、邮箱、联系方式、申请说明 |
| 新的发布申请 | 管理员 | 提交人、模型数、地块数、申请说明 |
| 加入申请通过 | 申请人 | 账号、一次性临时密码、首次登录改密提示 |
| 加入申请驳回 | 申请人 | 审核说明 |
| 发布申请通过 | 提交人 | 已发布提示 |
| 发布申请驳回 | 提交人 | 审核说明 |
| 发布申请过期 | 提交人 | 因已有更新版本发布而过期，请基于最新共享世界重提 |

管理员收件人由两部分合并：

1. 「管理员通知收件人」里配置的地址。
2. 团队成员中角色为管理员、状态为启用的账号邮箱。

申请人邮箱来源：

- 新加入申请必须在申请表填写通知邮箱。
- 管理员可以在「团队成员」页修改成员邮箱。
- 旧申请如果联系方式本身是邮箱，迁移时会自动写入 `email` 字段。

## 发送行为

- 通知在业务操作完成后异步发送，不阻塞申请、审核或发布。
- SMTP 未启用、缺少收件人或申请人没有有效邮箱时，会写入一条 `skipped` 记录。
- SMTP 连接失败、认证失败或超时，会写入一条 `failed` 记录，并在「最近发送记录」中显示错误。
- 审核通过/驳回本身不会因为邮件失败而回滚。
- 发布申请通过后，其他待审申请会被标记为过期，并分别通知对应提交人。

## 测试邮件

1. 填写 SMTP 配置并保存。
2. 勾选「启用邮件通知」。
3. 在测试收件人输入框填写地址；留空则发送到管理员收件人。
4. 点击「发送测试邮件」。
5. 到「最近发送记录」确认状态为 `sent`。

测试邮件使用**已保存**的配置。修改 SMTP 参数后，先保存再测试。

## 常见问题

### `ECONNREFUSED` / `ETIMEDOUT`

- 主机或端口不正确。
- 服务器防火墙拦截了出站 SMTP。
- 云主机封禁了 25 端口；优先使用 465 或 587。

### `Invalid login` / `535 Authentication failed`

- 使用了邮箱登录密码，但服务商要求 SMTP 授权码。
- 用户名不是完整邮箱地址。
- 服务商未开启 SMTP 服务。

### 发件人被拒绝

- `发件邮箱` 与 SMTP 账号不匹配。
- 服务商要求发件地址必须属于当前账号。
- 需要单独配置 SPF/DKIM 或企业发信白名单。

### 收不到邮件

- 检查垃圾邮件。
- 检查发送记录是否为 `sent`。
- 如果是 `sent` 但未收到，检查收件方反垃圾策略和发件域信誉。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/v1/admin/email-settings` | 读取配置，密码不回传 |
| `PUT` | `/api/v1/admin/email-settings` | 保存配置 |
| `POST` | `/api/v1/admin/email-settings/test` | 发送测试邮件 |
| `GET` | `/api/v1/admin/email-settings/log` | 最近 30 条发送记录 |

以上接口都需要管理员会话（`ncgxy_session` Cookie）。

## 数据表

- `email_settings`：单行 SMTP 配置。
- `email_delivery_log`：发送记录，保留最近查询所需的记录；当前页面显示 30 条。
- `app_user.email`：成员通知邮箱。
- `join_application.email`：申请时的通知邮箱。

## 安全建议

- SMTP 密码当前以明文保存在 `email_settings.password`，生产环境应限制数据库访问权限，并使用专用发信账号。
- 不要把 SMTP 密码写进前端环境变量或 Git。
- 审核通过邮件包含一次性临时密码，应确保收件邮箱可信。
- 建议为系统配置独立的发信邮箱，不要使用管理员个人邮箱。
