HOW IT WORKS

FROM AN IDEA TO A WORLD

01 / WHY

A WORLD BUILDER, NOT A MAP VIEWER

地图记录已经存在的地方。
Worldweave 让你决定，
哪里应该存在什么。

从一个地块开始，扩展边界、铺设道路、放置或生成建筑，调节这个世界的环境时间。然后把完成的版本发布成别人可以走进去探索的 3D 世界。

不是把一张地图搬到浏览器里，而是把“搭建、生成、拥有时间、发布与协作”放进同一张工作台。校园只是内置示例场景——同一个工作台可以做园区、展场、乐园，或任何等距世界。

01

从地块开始

世界不是一次性导入的。它从一个 12 × 12 的地块长出来，边界、道路与建筑都可以继续编辑。

02

让 AI 参与建造

用对话和参考图生成建筑与场景模型，每个阶段都经过视觉质检；生成后仍能选部件继续微调。

03

给世界一个时间

每个世界有自己的时刻、天气、风与人工照明。光线决定氛围，氛围决定这个世界怎么被记住。

04

发布，而不是导出

成员提交冻结版本，管理员用 3D 视图审核。通过后，访客看到的就是这份被认真确认过的世界。

03 / WORKFLOW

FROM A PLOT TO A PUBLISHED WORLD

四步，把一个想法
变成可以走进去的地方。

  1. 01

    扩展第一块地

    从空白沙盒开始，扩建地块、调整边界，为世界留出呼吸的地方。

  2. 02

    铺路，放置，或生成

    画出道路，放上模型；也可以直接描述一栋建筑，让 AI 从体块开始把它建出来。

  3. 03

    给世界一个时刻

    调好光照、天气与风。世界不是静态模型，它应该有傍晚，也应该有雨。

  4. 04

    提交，审核，发布

    冻结这一版世界，附上说明；管理员在 3D 视图里确认后，首页换上你的世界。

05 / QUICK START

MAKE A WORLD IN ONE AFTERNOON

把仓库跑起来，
开始你的第一块地。

需要 Node.js 20.19+、PostgreSQL 16+ 与 PostGIS 3.4+；如果只是想先看看，Docker Compose 会把数据库、API 和前端一起拉起来。

  • ✓ 自带示例沙盒与程序化资产
  • ✓ 首次启动自动创建管理员并强制改密
  • ✓ AI 能力可选配置，不影响世界编辑
阅读 README ↗ 环境变量 ↗

演示环境默认管理员：admin / Admin@12345。生产部署请务必替换。

worldweave — terminal 
# 在仓库根目录
docker compose up --build

# 打开世界
→ http://localhost:8080

# 默认管理员（仅演示）
→ admin / Admin@12345
# 前端
npm install
npm run dev

# 后端
cd server
cp .env.example .env
npm install
npm run db:migrate
npm run start:dev
